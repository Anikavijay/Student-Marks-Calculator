# Student Marks Calculator

## Description
A beginner-friendly Java project that accepts marks and calculates student results.

## Features
- Accepts marks as input.
- Validates marks within the range of 0 to 100.
- Counts failed subjects.
- Calculates the total marks.

## Technologies Used
- Java
- JOptionPane for input dialogs

## Concepts Used
- Variables and data types
- Loops
- If-else statements
- Input validation

## How to Run
1. Make sure Java is installed.
2. Save the source file as `Studentmarks.java`.
3. Compile: `javac Studentmarks.java`
4. Run: `java Studentmarks`
